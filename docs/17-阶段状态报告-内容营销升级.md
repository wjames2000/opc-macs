### 2.7 `recommendation_reason.go` — 智能推荐理由

创建 `internal/saas/recommendation_reason.go`（WBS 9.4.3）：

- `RecommendationReasoner` 结构体，封装 `runtime.Loader` 插件系统
- `GenerateReasons()` — 对每个推荐任务生成 LLM-powered reason 文本
- `GenerateBatchReasons()` — 分批处理避免过量 LLM 调用
- 使用 `content_creator` 插件进行 LLM 推理
- 自动回退: 插件不可用或调用失败时保持原 reason
- `buildReasonPrompt()` — 构建包含 title/description/budget/platform/deadline 的结构化 prompt
- `parseReasonResponse()` — 清理 LLM 返回文本（去除引号/额外空白）
