## 文档结构说明

本文档采用三层结构组织：

```
Epic（史诗级功能）
  └─ Feature（功能模块）
       └─ User Story（用户故事，格式：角色 → 目标 → 价值）
            └─ Acceptance Criteria（验收标准）
```

## Phase B 用户故事 — 内容平台核心层

### Epic B1：Publish — 多平台一键发布

#### Feature B1.1：平台账号绑定

**US-B1.1.1 — 绑定平台账号**

> **作为** OPC-Agent 用户
> **我想要** 在系统内绑定我的抖音、小红书等平台账号
> **以便于** 后续一键发布内容到这些平台

**验收标准：**
- [ ] 支持 OAuth 标准授权流程绑定账号
- [ ] 支持通过 API Key / Cookie 方式绑定（对不支持 OAuth 的平台）
- [ ] 绑定过程中清晰展示所需权限范围
- [ ] 绑定成功后显示账号头像、名称和平台标识
- [ ] 同一平台支持绑定多个账号
- [ ] 绑定失败时显示明确错误原因和解决建议
- [ ] Token 过期时自动触发刷新或主动告警

**US-B1.1.2 — 管理平台账号**

> **作为** OPC-Agent 用户
> **我想要** 查看、编辑和解绑我已经绑定的平台账号
> **以便于** 管理我的跨平台账号矩阵

**验收标准：**
- [ ] 账号列表页面展示所有已绑定账号（含平台、账号名、绑定时间、状态）
- [ ] 支持按平台筛选账号
- [ ] 支持编辑账号别名（自定义命名）
- [ ] 支持解绑操作，解绑前二次确认
- [ ] 显示每个账号的 Token 有效期，即将过期时标识提醒

#### Feature B1.2：内容发布

**US-B1.2.1 — 创建发布任务**

> **作为** OPC-Agent 用户
> **我想要** 创建包含文案、图片/视频的发布任务，并选择目标平台和账号
> **以便于** 一次准备，多平台同步发布

**验收标准：**
- [ ] 发布表单包含标题、正文、媒体文件上传（图片/视频）、标签输入
- [ ] 支持从素材库选择已有内容
- [ ] 支持选择多个目标平台和每个平台对应的账号
- [ ] 选择平台后自动显示该平台的格式要求（视频比例、文案长度、标签数量）
- [ ] 内容适配器自动转换格式（如 16:9 → 9:16 裁切提示）
- [ ] 支持保存为草稿

**US-B1.2.2 — 内容适配预览**

> **作为** OPC-Agent 用户
> **我想要** 在发布前预览内容在各平台的实际展示效果
> **以便于** 确保内容在各平台显示正确

**验收标准：**
- [ ] 切换平台 Tab 可查看对应平台的效果预览
- [ ] 视频预览显示该平台推荐比例下的裁切结果
- [ ] 文案显示该平台格式下的排版
- [ ] 标签显示为该平台优化后的结果
- [ ] 预览可直接编辑调整

**US-B1.2.3 — 执行发布**

> **作为** OPC-Agent 用户
> **我想要** 执行发布任务，将内容发布到所选平台
> **以便于** 内容快速上线

**验收标准：**
- [ ] 支持「立即发布」和「定时发布」两种模式
- [ ] 发布时显示实时进度（如：抖音 ✅ 小红书 ⏳ 微信 ❌）
- [ ] 发布失败时自动重试（可配置重试次数）
- [ ] 发布完成后通知结果
- [ ] 发布日志记录每次发布的详细信息（请求、响应、错误）

**US-B1.2.4 — 发布日历**

> **作为** OPC-Agent 用户
> **我想要** 在日历视图上查看和管理我所有的发布计划
> **以便于** 规划内容排期

**验收标准：**
- [ ] 月视图/周视图切换
- [ ] 日历上展示每个日期的发布任务数量和平台标识
- [ ] 支持拖拽调整发布时间
- [ ] 点击发布任务可查看详情/编辑/取消
- [ ] 日历同步内容库的待发布素材

### Epic B2：Engage — 自动互动运营

#### Feature B2.1：评论管理

**US-B2.1.1 — 跨平台评论聚合**

> **作为** OPC-Agent 用户
> **我想要** 在一个页面查看所有平台的所有评论
> **以便于** 统一管理用户互动

**验收标准：**
- [ ] 聚合显示各平台的最新评论，按时间倒序
- [ ] 每条评论显示来源平台、所属内容、评论用户、评论内容和时间
- [ ] 支持按平台/内容/时间段筛选评论
- [ ] 支持标记已读/未读
- [ ] 支持评论搜索

**US-B2.1.2 — 智能评论回复**

> **作为** OPC-Agent 用户
> **我想要** 让 AI 自动回复评论
> **以便于** 减少手动回复工作量，提升互动率

**验收标准：**
- [ ] 支持设置自动回复规则（关键词触发、全部回复、仅负面/正面）
- [ ] AI 回复内容保持品牌语气（可在设置中定义品牌语气描述）
- [ ] 回复前显示 AI 生成的回复内容，支持人工确认或修改
- [ ] 支持白名单（自动回复）和黑名单（不回复或特殊处理）
- [ ] 支持不同平台设置不同的回复规则
- [ ] 自动回复记录可在日志中查看

**US-B2.1.3 — 评论挖掘**

> **作为** OPC-Agent 用户
> **我想要** AI 自动分析评论内容，识别购买意向和潜在客户
> **以便于** 及时跟进高意向用户

**验收标准：**
- [ ] AI 自动标记高转化信号评论（如「怎么买」「多少钱」「链接」）
- [ ] 展示评论热度分析和情感趋势
- [ ] 支持导出高意向评论列表
- [ ] 高意向评论支持一键回复引导话术

## Phase A 用户故事 — 内容创作增强层

### Epic A1：video_script — AI 视频脚本生成

#### Feature A1.1：脚本智能创作

**US-A1.1.1 — 生成视频脚本**

> **作为** 内容创作者
> **我想要** 输入一个主题，AI 自动生成完整的短视频脚本
> **以便于** 快速产出视频创意

**验收标准：**
- [ ] 输入主题后 5 秒内生成完整脚本（含分镜、话术、画面建议）
- [ ] 生成的脚本包含：标题、开场钩子、分镜表、结尾 CTA、推荐标签
- [ ] 每个分镜包含：时长、画面描述、配音文案、字幕文案、运镜建议
- [ ] 脚本总时长与目标时长误差 < 10%

**US-A1.1.2 — 平台风格适配**

> **作为** 内容创作者
> **我想要** 脚本自动适配不同平台的风格要求
> **以便于** 一个主题快速适配多平台

**验收标准：**
- [ ] 选择「抖音」时脚本为 15-60s 快节奏风格
- [ ] 选择「B站」时脚本为 3-15min 深度风格
- [ ] 选择「小红书」时脚本为 30-120s 种草风格
- [ ] 各平台脚本的话术、结构、节奏风格差异明显且符合平台调性

**US-A1.1.3 — 批量脚本生成**

> **作为** 内容创作者
> **我想要** 一个主题生成多个不同角度的脚本变体
> **以便于** A/B 测试不同内容方向

**验收标准：**
- [ ] 支持一次生成最多 5 个不同角度的脚本
- [ ] 每个变体有差异化的开场钩子和内容结构
- [ ] 变体间不重复，覆盖不同话术风格

### Epic A2：trend_radar — 热点雷达

#### Feature A2.1：热点监测

**US-A2.1.1 — 查看实时热榜**

> **作为** 内容创作者
> **我想要** 实时查看各平台的热门话题排行榜
> **以便于** 抓住热点创作流量内容

**验收标准：**
- [ ] 展示抖音、小红书、B站、微博等平台热榜
- [ ] 每条话题显示：排名、话题名、热度指数、趋势方向（上升/峰值/下降）
- [ ] 支持按平台筛选
- [ ] 热榜数据每 30 分钟自动更新
- [ ] 支持搜索话题

**US-A2.1.2 — 生成选题推荐**

> **作为** 内容创作者
> **我想要** AI 根据我的账号定位推荐适合创作的热门话题
> **以便于** 在热门话题中找到适合我创作的方向

**验收标准：**
- [ ] 输入我的垂直领域（如「美食」「科技」）后过滤相关话题
- [ ] 每条推荐含推荐理由（热度 + 相关性 + 竞争度分析）
- [ ] 显示推荐置信度
- [ ] 点击推荐话题可直接进入 video_script 创作

**US-A2.1.3 — 生成热点报告**

> **作为** 内容创作者
> **我想要** 自动生成每日/每周热点趋势报告
> **以便于** 规划创作排期

**验收标准：**
- [ ] 日报：当天热榜 TOP10 + 推荐选题 3-5 个
- [ ] 周报：本周趋势回顾 + 下周趋势预测
- [ ] 报告可导出为 PDF/Markdown
- [ ] 报告包含可视化图表（趋势图、词云）

### Epic A3：tag_generator — AI 标签推荐

#### Feature A3.1：智能标签

**US-A3.1.1 — 生成内容标签**

> **作为** 内容创作者
> **我想要** 根据我的内容自动生成推荐标签
> **以便于** 内容获得更多曝光

**验收标准：**
- [ ] 输入内容标题/描述后自动生成相关标签
- [ ] 区分核心标签（高流量）和辅助标签（精准流量）
- [ ] 每个标签标识热度等级（火爆/上升/长尾）
- [ ] 每个标签附推荐理由
- [ ] 标签数量可配置（5-20 个）

**US-A3.1.2 — 平台标签策略**

> **作为** 内容创作者
> **我想要** 不同平台获得不同的标签组合策略
> **以便于** 在每个平台都获得最佳曝光

**验收标准：**
- [ ] 抖音标签策略：3-5 个流量标签 + 2-3 个精准标签
- [ ] 小红书标签策略：2-3 个大标签 + 5-8 个小标签
- [ ] B站标签策略：5-10 个话题标签
- [ ] 标签策略说明清楚易理解

## Phase C 用户故事 — 商业化变现层

### Epic C1：Marketplace — 内容交易市场

#### Feature C1.1：商家发单

**US-C1.1.1 — 发布推广任务**

> **作为** 商家/品牌方
> **我想要** 在平台上发布内容推广任务
> **以便于** 找到合适的创作者为我制作和推广内容

**验收标准：**
- [ ] 任务发布表单包含：标题、描述、目标平台、结算方式、预算、要求
- [ ] 支持选择 CPS/CPE/CPM 三种结算方式
- [ ] 可设置创作者门槛（最低粉丝数、最低互动率、垂直领域）
- [ ] 可设置截止日期和最大接单人数
- [ ] 发布前预览任务详情
- [ ] 发布后任务出现在任务广场
- [ ] 支持保存为草稿

**US-C1.1.2 — 查看和管理任务**

> **作为** 商家/品牌方
> **我想要** 查看我发布的所有任务状态
> **以便于** 跟踪推广进度

**验收标准：**
- [ ] 任务列表展示所有任务（状态筛选：开放/进行中/已完成/已取消）
- [ ] 每个任务展示：标题、预算、已接单数、状态、操作
- [ ] 点击任务查看详情（接单创作者列表、交付内容、数据报告）

**US-C1.1.3 — 审核交付内容**

> **作为** 商家/品牌方
> **我想要** 查看和审核创作者提交的内容
> **以便于** 确保内容质量符合要求

**验收标准：**
- [ ] 查看创作者提交的发布链接和数据截图
- [ ] 可批准、驳回或要求修改
- [ ] 驳回时填写修改意见
- [ ] 超过截止日期未审核默认自动批准

**验收标准：**
- [ ] 本月收益、累计收益、待结算金额、已提现金额
- [ ] 按平台/结算方式分类的收益分布
- [ ] 收益趋势图

### Epic C2：Settlement — 结算与钱包

#### Feature C2.1：自动结算

**US-C2.1.1 — 任务自动结算**

> **作为** 系统
> **我想要** 在任务完成后根据结算方式自动计算创作者收益
> **以便于** 及时准确完成结算

**验收标准：**
- [ ] CPS 结算：根据实际成交额 × 费率自动计算
- [ ] CPE 结算：根据有效互动数 × 单价自动计算
- [ ] CPM 结算：根据总曝光量 ÷ 1000 × CPM 单价自动计算
- [ ] 平台佣金自动扣除（分级费率）
- [ ] 结算单自动生成（商家侧 + 创作者侧）

#### Feature C2.2：钱包提现

**US-C2.2.1 — 查看钱包和提现**

> **作为** 创作者
> **我想要** 查看我的钱包余额并发起提现
> **以便于** 将收益变为实际收入

**验收标准：**
- [ ] 钱包页面显示：总余额、冻结余额、可提现余额、累计收益
- [ ] 提现最低金额 ¥100，单次最高 ¥50,000
- [ ] 支持支付宝/微信/银行卡提现
- [ ] 提现前需绑定收款方式
- [ ] 提现完成后通知结果
- [ ] 交易流水记录完整可查

#### Feature C2.3：评价与信用

**US-C2.3.1 — 互评**

> **作为** 商家/创作者
> **我想要** 在交易完成后评价对方
> **以便于** 帮助其他用户了解对方的信誉

**验收标准：**
- [ ] 交易完成后双方可互评
- [ ] 评分 1-5 星
- [ ] 多方维度评分（内容质量/交付及时性 etc.）
- [ ] 评价后不可修改

**US-C2.3.2 — 信用分**

> **作为** 平台运营方
> **我想要** 系统自动计算和更新用户信用分
> **以便于** 保障交易市场健康运营

**验收标准：**
- [ ] 新用户初始信用分 100
- [ ] 信用分自动加减（根据交易行为）
- [ ] 信用分 < 60 限制功能
- [ ] 信用分变化在用户页面可见
