## 1. 设计愿景与目标

### 设计愿景

为 OPC（一人公司）创业者打造一个 **"AI 团队指挥中心"**——让一个人在浏览器中就能像管理一支完整团队一样，与多个 AI Agent 协作、监控产出、控制成本。

### 设计目标

| 目标 | 说明 |
|------|------|
| **效率优先** | 核心操作三步内完成，减少点击层级 |
| **状态透明** | 每个 Agent 的执行状态、Token 消耗、处理历史一目了然 |
| **成本可控** | 费用估算实时可见，没有隐藏消耗 |
| **专业可信** | 视觉风格传递"可靠的生产力工具"而非"玩具式 AI" |

### 目标用户

- **身份**：OPC 创业者 / 独立开发者 / 超级个体
- **技术能力**：具备 Go 开发能力，熟悉命令行
- **核心痛点**：需要可视化地管理多个 AI Agent，追踪成本，查看产出物
- **使用场景**：
  - 日常：在对话界面中给 Agent 分配任务
  - 管理：查看各 Agent 的 Token 消耗和费用
  - 配置：切换模型 Provider、管理插件
  - 复盘：查看历史任务和 Agent 输出质量

### 2.2 字体系统

| 层级 | 字号 | 字重 | 行高 | 用途 |

## 5. 响应式策略

### 5.1 断点布局

| 尺寸 | 布局 | 说明 |
|------|------|------|
| **桌面 ≥ 1280px** | 侧边栏展开 + 三列内容 | 完整功能体验 |
| **笔记本 1024-1280px** | 侧边栏收起图标 + 两列 | 侧边栏自动收缩 |
| **平板 768-1024px** | 底部 tab 导航 + 单列 | 触控友好间距 |
| **手机 < 768px** | 全屏单列 + 浮动操作按钮 | 核心功能优先 |

### 5.2 自适应处理

| 组件 | 桌面 | 平板 | 手机 |
|------|------|------|------|
| 侧边栏 | 展开 240px | 图标 60px | 底部 Tab |
| StatCard | 4 列网格 | 2 列网格 | 垂直堆叠 |
| 对话列表 | 显示完整 | 显示摘要 | 仅标题 |
| 表格 | 全部列 | 隐藏次要列 | 卡片视图 |
| 设置表单 | 两列 | 单列 | 单列 |

## 6. 技术实现建议

### 6.1 技术栈推荐

| 层 | 技术选型 | 理由 |
|----|----------|------|
| 框架 | React 18 + TypeScript | 生态成熟，团队熟悉 |
| 路由 | React Router v6 | 标准方案 |
| 状态管理 | Zustand | 轻量，无 boilerplate |
| UI 组件 | Tailwind CSS + HeadlessUI | 快速实现设计系统 |
| 图表 | Recharts | 轻量 React 图表库 |
| HTTP | fetch API | 无额外依赖 |

### 6.2 API 对接

与现有 CLI 后端共用核心逻辑，Web 模式下增加 HTTP 接口层：

```
POST /api/v1/task     - 提交任务
GET  /api/v1/agents   - 获取 Agent 列表
GET  /api/v1/usage    - 获取用量统计
GET  /api/v1/history  - 获取历史记录
PUT  /api/v1/config   - 更新配置
GET  /api/v1/healthz  - 健康检查（已有）
```
